Objective is that each server or group of servers ha specialized roles.

## CLASSES of machines 

### NODE Class
- This is currently only github
- Home located reprogrammed wifi router is being configured as well.
- Longer term increase soverign replacement or addition to github. 
- these machines are typically repurposed hubs like wifi routers with attached ssd storage. 
- They feature true 1G network and high resilience/recovery to power failure.
- Unlike github edits will be intantaneously applied.
- Local/low latency to terminal machines.
- They lose their config on crash and need to seek or receive  new config from github on power on.

### TERMINAL Class
- Typically lowest usable spec laptop/phone/tablet
- Minimum Debian or freebsd laptop: Minimum 12in screen, 4Gb ram, ssd. inc googlebook etc
- Commonly but not exclusively: X11, OpenBox, Xfce4 tools

### STARLING Class
- Wide range of low cost/open/public resources often with no admin access and limited resoures
- The object is to create a Murmuraton from the Starlings where the murmuration acts
  like a more capable resource than the individuals or the sum of its starlings.
